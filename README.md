# SmartTutor

Приложение‑тьютор для обучения с чат‑интерфейсом, учебными планами и напоминаниями.

## Возможности
- Чат с ИИ‑тьютором.
- Создание учебного плана и прохождение шагов.
- Отметка прогресса и активности в профиле.
- Напоминания по учебным задачам.

## Требования
- Android Studio (актуальная версия).
- JDK 17.
- Android SDK (устанавливается через Android Studio).

## Быстрый запуск (Android Studio)
1) Откройте Android Studio.
2) File → Open → выберите папку проекта `SmartTutor`.
3) Дождитесь синхронизации Gradle.
4) В верхней панели выберите устройство (эмулятор или телефон).
5) Нажмите **Run** ▶️.

## Сборка APK (GUI)
Android Studio → **Build → Build Bundle(s) / APK(s) → Build APK(s)**  
Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`

## Сборка APK (CLI)
```powershell
cd D:\SmartTutor
.\gradlew :app:assembleDebug
```

## Настройка API‑ключей (локально)
Создайте файл `local.properties` в корне проекта и добавьте:
```
OPENROUTER_API_KEY=ваш_ключ
OPENROUTER_MODEL=ваша_модель
GEMINI_API_KEY=ваш_ключ
```

## Использование
- Задавайте вопросы в чате — тьютор ответит по теме.
- Для создания учебного плана:
  - согласитесь на предложение бота **или**
  - напишите: **«Создай план»**.
- После запуска плана ответы идут строго по шагам.
- Команда **«дай ответ»** пропускает текущий шаг без увеличения прогресса.

## GitHub (без консоли)
Можно загрузить проект через GitHub Desktop:
1) Установите GitHub Desktop.
2) File → Add Local Repository… → выберите папку `SmartTutor`.
3) Commit → Publish repository.
